# VirratPOS

**VirratPOS** is a modern, premium UI/UX remaster of the StoreGo Point of Sale SaaS platform. Built on a robust Laravel backend, VirratPOS focuses on delivering an exceptional, responsive, and highly aesthetic user experience for modern retail and e-commerce management.

## Tech Stack

- **Backend:** Laravel (PHP)
- **Database:** MySQL
- **Templating:** Blade
- **Styling & Interaction:** Vanilla CSS/JS (No heavy frontend framework migrations)

## Features

VirratPOS encompasses the entire lifecycle of a modern SaaS POS platform, including:

- **Dashboard (Application Shell):** A sleek, intuitive command center.
- **Products & Inventory:** Streamlined management for physical and digital products.
- **Orders & Customers:** Comprehensive tracking and customer relationship management.
- **Point of Sale (POS):** Fast, reliable, and secure checkout interface.
- **Staff & Roles:** Flexible role-based access control.
- **Analytics:** Real-time insights and reporting.
- **Subscriptions & Payments:** Integrated billing with multiple payment gateways (PayPal, Stripe, PayTabs, Cashfree, etc.).
- **Store Builder & Themes:** Customizable storefronts for end-users.

## Getting Started for Developers

If you are joining the development team, please refer to the [Team Setup & Workflow Guide](README-TEAM-SETUP.md) for step-by-step instructions on setting up your local XAMPP environment, configuring your `.env`, and understanding our Git branching rules.

### Quick Start Summary

1. Clone the repository and install dependencies (`composer install`, `npm install`).
2. Copy `.env.example` to `.env` and configure your local database credentials.
3. Run migrations and seed the database (`php artisan migrate`, `php artisan db:seed`).
4. Build assets (`npm run dev`).
