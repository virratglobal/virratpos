# Integrations Audit

## Supported Integrations
- **Twilio**: SMS integration for notifications.
- **WhatsApp & Telegram**: Order notifications/buttons.
- **Email**: SMTP configurations, templates.
- **Google Analytics / Tracking Pixels**: Facebook Pixel, Google Analytics, etc.
- **Webhooks**: Custom webhooks supported via the `Webhook` model.
- **Custom Domains**: Managed via `CustomDomainRequest` and `Store` subdomain settings.
